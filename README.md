## 👋 About Me

I'm **Alessandro Cardarelli**, a Full Stack Developer with a strong passion for **front-end development**. My journey into tech didn't start with code — it started with **video games and hardware**, which slowly evolved into a genuine passion for software development.

Today I build cross-platform mobile apps with **Flutter** and modern web apps with **Vue.js / Nuxt.js**, while constantly pushing myself to learn more about the backend world.
